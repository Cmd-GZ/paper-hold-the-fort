# 战线模式 · 快速上手（给服主）

> 这份指南只讲**在游戏里打命令**。不需要改任何文件，也不需要懂代码。
> 全程大约 5 分钟，只需要做一次。

---

## 第 0 步：装插件

把 `HoldTheFort-x.x.x.jar` 丢进服务器的 `plugins/` 文件夹，重启服务器。

日志里看到这两行就说明装好了：

```
[HoldTheFort] 还没有任何地图。OP 在战场世界里执行 /htf setup 即可现场做一张。
[HoldTheFort] Hold the Fort v0.1.0-SNAPSHOT 已启用，成功加载 0 张地图
```

> 「0 张地图」是正常的 —— 插件不自带地图，下面现场做一张。

---

## 第 1 步：走进战场世界

先到这个服专门给这个游戏用的世界：

```
/gw tp world_htf
```

> 没有 `/gw` 命令的话，用你自己服的多世界插件进到战场世界即可。
> **战场世界必须和大厅世界不是同一个。**
>
> ⚠️ **千万别站在大厅世界里做地图**，插件会拦住你。

---

## 第 2 步：开始做地图

```
/htf setup
```

背包里会多出一根叫 **「战线标尺」** 的棍子。

---

## 第 3 步：点出战线（重点）

拿着标尺：

**左键点一下地面 → 右键点一下地面 = 画好一条线**

聊天框会提示：

```
已记录一个点，再点一下组成一帧
第 1 帧已记录
```

**重复 5 次**（最少 3 次，建议 5～9 次），得到 5 条平行的线。

怎么理解这 5 条线：

| 你点的 | 代表 |
|---|---|
| 一条线的**两个端点** | 这一帧战线有多长 |
| 一条线摆在**哪里** | 这一帧战线在什么位置 |
| 5 条线的**先后顺序** | 战线从哪走、往哪走 |

所以最简单的做法：**在地面上刷 5 条横向的线，从红方基地那边一路排到蓝方基地那边。**

```
        线5   ──────────────────   ← 最后一条（离蓝方基地最近）
        线4   ──────────────────
        线3   ──────────────────
        线2   ──────────────────
        线1   ──────────────────   ← 第一条（离红方基地最近）
```

> 点错了不用重来：`/htf setup undo` 撤一步，`/htf setup reset` 全部清空重来。

---

## 第 4 步：记两队出生点

走到**红方**该出生的位置，站好，打：

```
/htf setup spawn red
```

再走到**蓝方**该出生的位置，站好，打：

```
/htf setup spawn blue
```

> 记的是你**站的位置**，所以站准一点。

---

## 第 5 步：保存

```
/htf setup done
```

成功时会看到两行读数：

```
[Frontline] [world_htf] 起点→蓝方基地 64.0 格 | 起点→红方基地 64.0 格 | V₀ = 0.60 格/秒 | 常规期约 1 分 47 秒 | 共 5 个关键帧
[Frontline] [world_htf] 开局站位：红方 (0, -100) = 后方 | 蓝方 (0, 100) = 前方
```

**只要看到「红方 … = 后方」，就做对了。**

> 如果写的是「前方」，说明红蓝出生点记反了，用 `/htf setup` 重做一次即可。

地图会保存在 `plugins/HoldTheFort/maps/world_htf.yml`。**以后再也不用做了。**

---

## 第 6 步（可选）：铺一层平地

战场还是坑坑洼洼的话：

```
/htf build world_htf
```

会在**你当前站着的世界**铺一层平整地面，大约 4 秒。

> 自己搭的场地就不用执行这条。

---

## 第 7 步：开一局

让玩家打：

```
/htf join red      加入红方
/htf join blue     加入蓝方
/htf join          不加队，开局时自动分到人少的一边
/htf leave         退出
```

**两队都有人**之后，自动 10 秒倒计时开局。

自己一个人想试试：

```
/htf start
```

---

## 玩法一句话

**站到战线对面（敌人那边）就会推线。**
红方越线的人多，战线就往蓝方基地走；推到尽头就赢。

---

## 出不来了怎么办

| 你看到的 | 意思 | 怎么办 |
|---|---|---|
| 打 `/htf` 没反应 | 不是 OP | 给自己 op |
| **点错了想重来** | —— | `/htf setup reset` 清空本世界的帧与出生点 |
| **想彻底删掉这张地图** | —— | `/htf map remove world_htf` |
| 「战场世界就是大厅世界」 | 地图建在大厅世界里了 | 换到战场世界重做，或改 `config.yml` 的 `lobby.world` |
| 「你现在站在大厅世界里建场」 | 站错世界了 | `/gw tp world_htf` 再试 |
| 「至少需要 3 个关键帧」 | 线点少了 | 继续点，凑够 3 条 |
| 「有一个点还没配对」 | 只点了左键没点右键 | 再点一下右键 |
| 「还没记红方出生点」 | 忘了第 4 步 | `/htf setup spawn red` |
| 「世界 xxx 不存在」 | 战场世界没加载 | 用世界插件加载它 |
| 两队都有人了却不开局 | 有人没 `/htf join` | 确认两边都显示已加入 |
| 日志里红方显示「前方」 | 出生点记反了 | 重做一次地图 |
| 开局后战线不动 | 没人越线 | 正常，站到对面去 |

## 想调数值（可选）

`plugins/HoldTheFort/config.yml`，改完重启：

| 字段 | 默认 | 含义 |
|---|---|---|
| `defaults.speed` | `0.6` | 战线每秒走几格，**想更快就调大** |
| `match.min_players` | `2` | 最少几个人才能开 |
| `match.team_limit` | `8` | 每队最多几个 |
| `accel.t1_minutes` | `8` | 第几分钟开始加速 |
| `accel.tmax_minutes` | `15` | 第几分钟强制结束 |

> 一局大概多久？看第 5 步那行读数里的「常规期约 …」。
